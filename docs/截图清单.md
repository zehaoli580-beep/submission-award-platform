# 大作业报告截图清单

> 使用方法：在桌面新建一个文件夹（如 `大作业截图`），按下表逐张截图存进去。
> 截图工具：`Win + Shift + S`（区域截图）。每张图尽量**只截关键区域**，不要全屏乱截。
> 报告约需要 **22 张图**，全程约 40 分钟。建议按顺序做，边做边截。

## 前置：启动三件套（每次重新开机后都要做）

1. 双击 `D:\dev-tools\mysql-8.4.7\start-mysql.bat`（黑窗口保持开着）
2. VS Code 打开 `submission-award-platform\backend` 文件夹 → 左侧弹簧图标（Spring Boot Dashboard）→ 点 Run
3. VS Code 打开 `submission-award-platform\frontend` 文件夹 → 顶部菜单 Terminal → New Terminal → 输入 `npm run dev`
4. 浏览器打开 `http://localhost:5173`
