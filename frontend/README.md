# 投稿/评奖平台 · 前端说明

技术栈:Vue 3 + Vite + Element Plus + Axios(开发工具:VS Code)

## 启动步骤

1. **先启动后端**(见 `../backend/README.md`)和 MySQL
2. 安装依赖(首次):`npm install`
3. 启动开发服务器:`npm run dev`
4. 浏览器访问 http://localhost:5173

> 开发期跨域已由 `vite.config.js` 的 proxy 解决:`/api` 与 `/files`
> 请求会被代理转发到 http://localhost:8080,无需后端额外配置。

## 已实现(步骤 3)

- 登录/注册页(注册角色限 AUTHOR/REVIEWER,与后端校验一致)
- 路由角色守卫:未登录 -> /login;访问非本角色页面 -> 重定向回自己工作台
- 刷新页面不掉线(Session 恢复 + /api/auth/me)
- 作者工作台:
  - 投稿表单(标题/分类/简介/文件,前端先校验扩展名白名单)
  - 我的稿件列表(状态标签、文件大小、下载链接)
  - 流转记录抽屉(时间线展示 operation_log,报告截图素材)
  - "退修改"稿件的一键修改重投(换文件/改简介,重新送审)

## 已实现(步骤 4)

- 审稿工作台(ReviewerHome):
  - 我的评审任务列表(文件下载/状态标签),提交意见抽屉(评分/结论/意见)
  - 奖项评分 Tab:对"评审中"奖项的各提名打分,支持回显与反复修改
- 管理后台(AdminHome):
  - 待初审稿件池:通过并分配审稿人(多选弹窗)/初审退稿
  - 外审与终审:查看全部意见、追加审稿人、终审决议(录用/退修改/退稿)
  - 奖项管理:创建奖项、开启评审、从"已录用"池提名、公示定奖(名额可配)、查看提名与结果
- 获奖公示页(AwardList,所有角色可见,顶栏入口):
  - 已公示奖项展示排名(奖牌标记/终评分/获奖与落选标签)
  - 未公示奖项仅显示状态,提名不公开

## 已实现(界面增强轮)

- 作品预览组件(MediaPreview,全部工作台复用):
  - 图片 -> 表格内缩略图,点击看大图
  - 视频(mp4/mov/webm) -> 点击"播放"弹窗在线播放(数字媒体平台特色功能)
  - 其他类型 -> 下载链接
- 管理后台:顶部数据仪表盘(待初审/外审中/已录用/退修改/用户/奖项 6 张统计卡片,各操作后自动刷新)
- 作者工作台:顶部个人稿件概览条(全部/待初审/外审中/已录用/退修改)
- 获奖公示页:领奖台大卡片(金/银/铜渐变配色 + 终评分进度条 + 作品预览)+ 完整排名表
- 登录页:双栏品牌化布局(左侧平台特性展示区 + 右侧登录卡,窄屏自适应)
- 整体:主内容区浅灰底色、顶栏吸顶、品牌 logo 点缀

## 目录结构

```
frontend/
├── index.html
├── package.json
├── vite.config.js        # 端口 5173 + /api /files 代理
└── src/
    ├── main.js           # 入口:注册 Element Plus(中文) + 路由
    ├── App.vue
    ├── api/
    │   ├── request.js    # axios 封装:Result 结构拦截、未登录跳转
    │   └── index.js      # 全部后端接口调用
    ├── router/index.js   # 路由 + 角色守卫
    ├── store/auth.js     # 登录态(响应式)
    ├── utils/format.js   # 状态/角色中文名、文件大小格式化
    └── views/
        ├── Login.vue     # 登录/注册(双 Tab)
        ├── Layout.vue    # 顶栏布局(角色标签/公示入口/退出)
        ├── AuthorHome.vue# 作者工作台
        ├── ReviewerHome.vue  # 审稿工作台(任务+奖项评分)
        ├── AdminHome.vue     # 管理后台(初审/终审/奖项管理)
        └── AwardList.vue     # 获奖公示页
```
